## How to upgrade a row

1. Run the step in your org (commands in [SALESFORCE-CLI.md](SALESFORCE-CLI.md)).
2. Record the result and evidence in [ORG-VALIDATION.md](ORG-VALIDATION.md).
3. Replace `NOT VERIFIED (...)` above with `VERIFIED <date> - ORG-VALIDATION #n` and add the screenshot file name.
4. If a step failed, write what failed and what you changed. A fixed failure is better interview material than a clean claim.
